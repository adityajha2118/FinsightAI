# FinSight AI — Dataset Documentation

## Raw Datasets (NOT in this repo — too large for GitHub)

All raw datasets are stored in Google Drive.

**Download Link:** [FinSight AI Datasets — Google Drive](INSERT YOUR GOOGLE DRIVE FOLDER LINK HERE after uploading)

### How to Download

**Option A — Manual:**
Download each file from the Drive link above and place in
the correct folder under `data/raw/`

**Option B — Script (run from FinSight-AI/ root):**
```bash
python scripts/download_data.py
```

## Dataset Sources

| Dataset | Source | Rows | Purpose |
|---|---|---|---|
| customer_data.csv | Kaggle BankChurners | 10,127 | Churn prediction |
| transactions.csv | Kaggle Credit Card Fraud | 1.3M | Fraud + spending analysis |
| bank_transactions.csv | Synthetic | 2,512 | Inactivity detection |
| bank_campaign.csv | UCI Bank Marketing (sample) | 100 | Campaign analytics |
| kyc_part1.csv | Synthetic AML transactions | 50,000 | AML signals |
| kyc_part2.csv | Synthetic KYC client profiles | 2,000 | KYC risk scoring |
| cfpb_complaints.csv | CFPB public dataset | 24,665 | Complaint intelligence |
