# Campaign Agent

## Purpose
Analyzes marketing campaign performance and predicts conversion likelihood for targeted outreach.

## Capabilities
- Retrieve campaign statistics and channel breakdowns
- Predict conversion probability for a given customer profile
- Identify optimal contact methods and timing

## Implementation
- Analysis: `src/campaign_analytics/campaign_analysis.py`
- Prediction: `src/campaign_analytics/campaign_prediction.py`
- API Endpoints: `GET/POST /api/campaign/*`
